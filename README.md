# 💰 Better Wallet

A modern and responsive personal finance and budget management web application built with React, Vite, Firebase Authentication, and Firestore.

Better Wallet helps users create and manage budgets, track expenses, monitor spending analytics, receive budget alerts, and securely store financial data with real-time cloud synchronization.

---

# ✨ Features

- 🔐 Firebase Authentication
- 🔑 Secure Login & Registration
- 🔄 Persistent Login Sessions
- 🗑️ Secure Account Deletion
- 💰 Create & Manage Budgets
- 🔄 Repeating Budgets
- ⏸️ Hold & Resume Budgets
- 💸 Add & Manage Expenses
- ✏️ Edit & Delete Expenses
- 📊 Spending Analytics
- 🔔 Budget Threshold Notifications
- ⚡ Real-time Firestore Synchronization
- 🌓 Dark Mode

# 🚀 Getting Started

## 1️⃣ Clone the Repository

    git clone https://github.com/samirDbala/better-wallet.git

---

## 2️⃣ Navigate to Project Folder

    cd better-wallet

---

## 3️⃣ Install Dependencies

    npm install

---

## 4️⃣ Create Firebase Project

Go to the Firebase Console and:

- Create a new Firebase project
- Enable Authentication
- Enable Firestore Database

---

## 5️⃣ Enable Authentication

Inside Firebase Authentication:

- Enable Email/Password authentication

---

## 6️⃣ Create Environment Variables

Create a `.env` file in the root directory and add:

    VITE_FIREBASE_API_KEY=your_api_key
    VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
    VITE_FIREBASE_PROJECT_ID=your_project_id
    VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
    VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
    VITE_FIREBASE_APP_ID=your_app_id

---

## 7️⃣ Start Development Server

    npm run dev
